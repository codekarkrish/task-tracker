# Task Tracker CLI

A simple command-line application to manage tasks.

## Features

- Add Task
- Update Task
- Delete Task
- Mark Task as Done
- Mark Task as In Progress
- List All Tasks
- Filter Tasks by Status

## Installation

git clone <repo-url>

cd task-tracker

npm install

## Usage

### Add Task

node src/index.js add "Learn Node.js"

### List Tasks

node src/index.js list

### Update Task

node src/index.js update 1 "Learn Express"

### Delete Task

node src/index.js delete 1

### Mark In Progress

node src/index.js mark-in-progress 1

### Mark Done

node src/index.js mark-done 1

### List Done Tasks

node src/index.js list done

### List Todo Tasks

node src/index.js list todo

### List In Progress Tasks

node src/index.js list in-progress
